# Village Defense – Silly Sniper Edition

A simple, fun first-person shooter where you (a sniper) and 3 loyal soldiers defend a village from waves of ridiculous Evil Invaders.

The invaders all have a large nose, skull cap, and long curly sideburns. They are very silly.

## How to Play

1. Open `index.html` in any modern browser (Firefox / Chrome / Edge work great on Kubuntu).
